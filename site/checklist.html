The tiers, for reference

Your agent walks these in order after the one paste. Each item's full detail lives in its own chapter; the stack and its install order start at Chapter 4.

Tier 0 · Machine base

  • Claude Code installed (the engine)
  • Tailscale, joined the mesh (Chapter 0, Step 6: the app on a Mac, the install script on Linux)
  • nixbash shell base (Linux), or tracked dotfiles + Brewfile (Mac)
  • jq and bun (1.2 or newer) on the PATH, the two tools every installer after this runs on (Chapter 4, Step 4a)

Tier 1 · The Brain

  • PAI installed (skills, hooks, agents), without overwriting any existing ~/.claude

Tier 2 · Memory & continuity

  • LMF4.1 on Linux (the mem command), persistent searchable memory, extraction model chosen (Claude Haiku or Ollama) and its server added with claude mcp add --scope user; on a Mac, LifeOS Cortex
  • A curated fact base: typed one-fact notes + an always-loaded index (Chapter 11)
  • *_forever repo + SessionEnd hook, ~/.claude auto-committing (raw history, private)

Tier 3 · Routing

  • claude-router installed (git clone into ~/Projects + ./install.sh, which installs the tier-router plugin from that clone)
  • Routing active: tier-router in claude plugin list, /cr answers, and the status line shows each routing decision

Tier 4 · Capabilities

  • claude-on-mac (Mac), Apple ecosystem
  • Your first custom skill / MCP connector / Fabric pattern

Tier 5 · Disaster recovery (already built in)

  • Confirm recovery = clone your *_forever repo onto a new machine (no separate tool)
  • Restore actually TESTED on a spare box / VM
